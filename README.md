# LabTracker

Персональный веб-трекер лабораторных, домашних и других учебных заданий. Проект создаётся поэтапно в рамках курса Fullstack. Текущая версия включает результаты лабораторных работ №1 и №2: интерфейс React + TypeScript и отдельный CRUD API на FastAPI с PostgreSQL и SQLAlchemy.

## Возможности проекта

- вести курсы и связанные с ними задания;
- видеть статус работы, дедлайн, оценку и максимальную шкалу;
- быстро находить ближайшие сроки и просроченные задания на сводке;
- открывать карточки курсов и заданий;
- переходить к демонстрационным формам создания и редактирования.
- создавать, читать, изменять и удалять курсы и задания через API;
- фильтровать задания по курсу, статусу и типу, сортировать по дедлайну;
- проверять входные данные и возвращать HTTP 404/422 с понятным описанием.

Frontend ЛР №1 пока использует mock-данные. Backend ЛР №2 уже сохраняет данные в PostgreSQL, но будет подключён к интерфейсу только в ЛР №5. Авторизация относится к ЛР №4.

## Пользовательские сценарии

1. Открыть сводку и проверить работы в процессе, просроченные и ближайшие дедлайны.
2. Перейти в список курсов и открыть карточку курса с его заданиями.
3. Открыть общий список заданий и отфильтровать его по курсу, статусу или типу.
4. Открыть карточку задания, увидеть дедлайн, статус и оценку.
5. Перейти в форму создания или редактирования задания.

## Экраны и маршруты

| Экран | Маршрут | Назначение |
| --- | --- | --- |
| Сводка | `/` | Счётчики, ближайшие дедлайны, просроченные задания и курсы |
| Курсы | `/courses` | Список курсов и демонстрационная форма создания |
| Карточка курса | `/courses/:id` | Описание курса и его задания |
| Задания | `/assignments` | Общий список и фильтры |
| Карточка задания | `/assignments/:id` | Данные задания: статус, срок, шкала и оценка |
| Новое задание | `/assignments/new` | Демонстрационная форма создания |
| Редактирование | `/assignments/:id/edit` | Демонстрационная форма редактирования |

Маршруты входа и регистрации сознательно не реализованы: по ТЗ они относятся к ЛР №4.

## Технологии

- React 19 + TypeScript;
- Vite;
- React Router;
- Ant Design с темой `#44546a`, радиусом 6px и системным шрифтом;
- собственный адаптивный CSS для структуры экранов.
- Python + FastAPI;
- PostgreSQL + SQLAlchemy 2;
- Pydantic для схем запросов, ответов и валидации;
- pytest для проверки валидации и CRUD.

## Запуск frontend

Требуется Node.js 20 или новее.

```bash
cd frontend
npm install
npm run dev
```

После запуска откройте адрес из вывода Vite (обычно `http://localhost:5173`). Для проверки production-сборки:

```bash
npm run build
```

## Запуск backend

Требуются Python 3.11 или новее и локальный PostgreSQL. Docker не используется.

Первичная подготовка PostgreSQL:

```sql
CREATE ROLE labtracker WITH LOGIN PASSWORD 'labtracker';
CREATE DATABASE labtracker OWNER labtracker;
```

Подготовка окружения и таблиц:

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env
python -m app.init_db
```

Запуск API:

```bash
uvicorn app.main:app --reload
```

Swagger будет доступен по адресу `http://127.0.0.1:8000/docs`, проверка состояния — `http://127.0.0.1:8000/health`.

Проверка проекта:

```bash
pytest -q
```

Интеграционный тест использует локальную базу из `.env`, создаёт временные записи и удаляет их после сценария.

## Модель данных ЛР №2

- `Course`: идентификатор, название, описание, дата создания;
- `Assignment`: курс, название, описание, тип, статус, дедлайн, максимальная и полученная оценка, даты создания и изменения;
- связь `Course 1 → M Assignment`; удаление курса каскадно удаляет его задания;
- ограничения БД не допускают отрицательную оценку, оценку выше шкалы и шкалу меньше единицы.

## API ЛР №2

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| `GET`, `POST` | `/api/courses` | Список и создание курсов |
| `GET`, `PUT`, `DELETE` | `/api/courses/{id}` | Карточка, изменение и удаление курса |
| `GET`, `POST` | `/api/assignments` | Список/фильтры и создание заданий |
| `GET`, `PATCH`, `DELETE` | `/api/assignments/{id}` | Карточка, изменение и удаление задания |

Для списка заданий поддерживаются параметры `course_id`, `status`, `type` и `sort`.
