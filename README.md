# LabTracker

Персональный веб-трекер лабораторных, домашних и других учебных заданий. Проект создаётся поэтапно в рамках курса Fullstack. Текущая версия — результат лабораторной работы №1: интерфейс React + TypeScript, маршрутизация, демонстрационные данные и единая тема Ant Design.

## Возможности проекта

- вести курсы и связанные с ними задания;
- видеть статус работы, дедлайн, оценку и максимальную шкалу;
- быстро находить ближайшие сроки и просроченные задания на сводке;
- открывать карточки курсов и заданий;
- переходить к демонстрационным формам создания и редактирования.

В ЛР №1 данные не сохраняются: это mock-данные. API, PostgreSQL и авторизация появятся в следующих лабораторных работах.

## Пользовательские сценарии

1. Открыть сводку и проверить работы в процессе, просроченные и ближайшие дедлайны.
2. Перейти в список курсов и открыть карточку курса с его заданиями.
3. Открыть общий список заданий и отфильтровать его по курсу, статусу или типу.
4. Открыть карточку задания, увидеть дедлайн, статус и оценку.
5. Перейти в форму создания или редактирования задания.

## Экраны и маршруты

| Экран | Маршрут | Назначение |
| --- | --- | --- |
| Сводка | `/` | Счётчики, ближайшие дедлайны, просроченные задания и курсы |
| Курсы | `/courses` | Список курсов и демонстрационная форма создания |
| Карточка курса | `/courses/:id` | Описание курса и его задания |
| Задания | `/assignments` | Общий список и фильтры |
| Карточка задания | `/assignments/:id` | Данные задания: статус, срок, шкала и оценка |
| Новое задание | `/assignments/new` | Демонстрационная форма создания |
| Редактирование | `/assignments/:id/edit` | Демонстрационная форма редактирования |

Маршруты входа и регистрации сознательно не реализованы: по ТЗ они относятся к ЛР №4.

## Технологии

- React 19 + TypeScript;
- Vite;
- React Router;
- Ant Design с темой `#44546a`, радиусом 6px и системным шрифтом;
- собственный адаптивный CSS для структуры экранов.

## Запуск frontend

Требуется Node.js 20 или новее.

```bash
cd frontend
npm install
npm run dev
```

После запуска откройте адрес из вывода Vite (обычно `http://localhost:5173`). Для проверки production-сборки:

```bash
npm run build
```

## Подготовка следующих этапов

В ЛР №2 появится `backend/` на FastAPI. Для него потребуется локальный PostgreSQL без Docker: создать БД и пользователя, заполнить `.env` по `.env.example`, затем создать таблицы из кода. Секреты и `.env` не коммитятся.
